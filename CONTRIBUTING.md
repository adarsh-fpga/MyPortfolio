# Contributing

This repository is a personal portfolio for Adarsh Kumar Thakur.

If you notice a bug, typo, broken link, or accessibility issue, please open an issue or submit a focused pull request.

## Local Setup

```bash
npm install
npm start
```

## Pull Requests

- Keep changes focused and easy to review.
- Run `npm run build` before opening a pull request.
- Do not add personal information, credentials, or generated build output.
- For content updates, keep the portfolio focused on VLSI, FPGA, RTL design, verification, AXI, SoC integration, and embedded systems.
