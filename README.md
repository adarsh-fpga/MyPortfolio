## Setup & Deployment

### Prerequisites
- Node.js (v20 recommended)
- npm

### Local Development
```bash
npm install
npm start
```

### Build for Production
```bash
npm run build
```

### Deploy to GitHub Pages
The site is automatically deployed via GitHub Actions on every push to the `master` branch.
